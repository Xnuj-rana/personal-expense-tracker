# 💰 Personal Expense Tracker

A simple Python project designed to help users track daily expenses, manage monthly budgets, and understand their spending habits. It provides an easy way to record transactions, organize expenses, and monitor personal finances.

---

## ✨ Features

- ➕ Add daily expenses
- 📋 View all recorded expenses
- 🗑️ Delete selected expenses
- 🔍 Search and filter expenses by category
- 💰 Calculate total spending
- 📅 Track monthly expenses
- 🎯 Set and monitor a monthly budget
- 📊 View category-wise expense summaries
- 📁 Export expense records to a CSV file
- 💾 Save expense data for future use

---

## 🛠️ Technologies Used

- Python
- Tkinter
- CSV
- JSON

---

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Open the terminal in the project folder.
5. Run the following command:

```bash
python main.py
```

6. The application will open, and you can start managing your expenses.

